# AI Chat Memory 用户手册

AI Chat Memory 用于把 DeepSeek、豆包和 Kimi 的网页对话同步到本地桌面应用，并提供搜索、分支查看和多格式导出。聊天数据库保存在本机，网页脚本只连接本地同步服务。

## 1. 安装

### 1.1 安装桌面端

1. 运行发布目录中的 `AI Chat Memory_*.msi`。
2. 完成安装后启动 AI Chat Memory。
3. 等待左下角状态变为“同步服务运行中”。

若应用无法显示界面，请先确认 Windows 已安装 WebView2 Runtime。

### 1.2 安装网页脚本

1. 在浏览器中安装 Tampermonkey。
2. 打开项目中的 `userscript/dist/ai-chat-memory.user.js`，将其导入 Tampermonkey。
3. 确认脚本已启用。
4. 打开并登录以下任一网站：

   - `https://chat.deepseek.com/`
   - `https://www.doubao.com/`
   - `https://kimi.com/` 或 `https://www.kimi.com/`

网页右上方会显示 AI Chat Memory 同步面板。面板中的服务状态应为“运行中”。

## 2. 同步聊天记录

网页同步面板提供两种操作：

- **开始同步**：检查会话状态，只上传新增或发生变化的会话，适合日常使用。
- **全量同步**：重新读取并上传平台可访问的全部会话，适合首次使用或补齐历史记录。

同步期间可以点击“停止同步”。同步结束后，回到桌面应用点击“刷新”查看最新数据。

网页脚本默认连接 `http://localhost:19820/api/v1`。如需修改，打开 Tampermonkey 的脚本菜单并选择“设置后端地址”；修改后刷新网页。

### DeepSeek ZIP 导入

桌面端顶部的“导入 ZIP”用于导入 DeepSeek 官方导出文件：

1. 点击“导入 ZIP”。
2. 选择 DeepSeek 导出的 ZIP 文件。
3. 等待导入完成，对话列表会自动刷新。

ZIP 文件最大支持 128 MB。该入口不用于豆包或 Kimi 文件。

## 3. 查找和阅读对话

### 搜索与筛选

- 在顶部搜索框输入标题或消息正文，按 Enter 执行搜索。
- 点击“日期筛选”设置开始日期和结束日期。
- 使用左侧“来源”切换全部来源、DeepSeek、豆包或 Kimi。
- 点击列表底部的加载按钮可以继续加载更多结果。

打开搜索结果后，正文上方会显示当前对话中的命中数量。使用上下箭头在命中项间跳转；启用“循环”后，到达末尾会返回开头。

### 对话分支

包含多个回答版本的 DeepSeek 对话会显示“分支预览”：

1. 点击“分支预览”查看分支图。
2. 点击任意节点，应用会选择从根节点到该叶节点的一条完整分支。
3. 返回“对话”视图后，只显示当前选中分支的消息。

搜索、阅读位置和导出均以当前选中的分支为准。

## 4. 导出聊天记录

### 4.1 选择导出内容

1. 打开一条对话，并在需要时先选择正确的对话分支。
2. 点击对话标题右侧的“更多操作”。
3. 选择“导出聊天记录”。
4. 应用会按“一条用户消息 + 紧随的助手消息”组成问答组，并默认全选当前分支中的全部问答组。
5. 使用复选框保留需要的问答组，也可以使用“全选”或“取消全选”。
6. 点击“导出所选”。

选择期间不能切换分支。取消选择模式或切换到其他会话会清空当前选择。

### 4.2 选择格式

导出窗口支持以下格式：

- **PNG**：白色背景的单张长图，保留 Markdown、代码块、表格、公式和 Mermaid 图表。
- **JPEG**：内容与 PNG 相同，使用 JPEG 压缩，适合需要较小文件的场景。
- **Markdown**：保留原始 Markdown 正文，适合继续编辑或纳入笔记系统。
- **JSON**：结构化数据，适合程序处理或二次转换。

“包含思考过程”默认关闭。开启后，仅在具有思考内容的助手消息中加入该内容；修改此选项后，应用会重新检查图片高度。

### 4.3 超长图片

PNG 和 JPEG 只能生成一张长图。进入格式选择窗口时，应用会提前检查所选内容的实际渲染高度：

- 检查期间图片格式暂时不可选；
- 超出 WebView 画布限制时，PNG 和 JPEG 会变灰，并自动选择 Markdown；
- 将鼠标放在灰色图片格式上可以查看原因；
- 可以返回选择界面减少问答组，或者直接使用 Markdown/JSON。

图片中的远程资源如果无法读取，会使用图片替代文本占位，不会阻止其他内容导出。

### 4.4 Markdown 格式

Markdown 文件使用以下结构：

```md
> 时间: 2025-07-14
> 平台: DeepSeek
---
**USER**：
用户正文

**ASSISTANT**：
助手正文
---
```

启用思考过程后，对应助手正文前会增加 `**ASSISTANT 思考过程**：` 区块。

### 4.5 JSON 格式

JSON 顶层包含：

- `version`：导出结构版本；
- `title`：对话标题；
- `time`：对话日期；
- `platform`：平台显示名称；
- `branch_id`：当前分支叶节点 ID，无分支时为 `null`；
- `exported_at`：导出时间；
- `messages`：按原始顺序排列的所选消息。

每条消息包含 `role`、`content` 和可用时的 `created_at`。启用思考过程后，有对应内容的消息会增加 `thinking`。JSON 不包含数据库 ID 或内部 metadata。

## 5. 应用设置

点击左下角齿轮打开设置。

### 外观

支持跟随系统、亮色和深色主题。图片导出始终使用稳定的白色背景，不受应用主题影响。

### 数据保存位置

默认数据库位于：

```text
%APPDATA%\dev.aichatmemory.desktop\chat_memory.db
```

点击“更改位置”会把现有数据库迁移到新目录，随后重启应用。迁移前建议备份 `chat_memory.db`，并确保目标磁盘有足够空间且当前用户具有写入权限。

### 窗口和托盘

- “关闭窗口后”可以选择每次询问、隐藏到托盘或完全退出。
- “点击托盘图标”可以选择显示菜单、打开主界面或不执行操作。
- 托盘菜单始终提供“打开对话归档”和“退出”。

### 允许的网页来源

每行填写一个完整的 HTTP 或 HTTPS Origin，不支持通配符。默认包含受支持平台的网页来源。只有白名单中的网页才能向本地服务提交数据。

### 同步密钥

开启同步密钥后：

1. 保存设置，应用会生成随机密钥。
2. 点击复制按钮复制密钥。
3. 打开 Tampermonkey 脚本菜单，选择“设置本地服务密钥”。
4. 粘贴密钥并刷新平台网页。

重新生成密钥后，所有网页脚本都需要更新。关闭密钥验证时，可以通过脚本菜单输入空值清除旧密钥。

### MCP（只读记忆库）

桌面应用可向 Cursor、Claude Desktop、OpenCode 等 MCP 客户端暴露本机已同步的聊天记录，仅支持只读检索与阅读。

**启用条件**

1. 桌面应用正在运行（可最小化到托盘）。
2. 设置中「MCP」开关为开启（默认开启）。
3. 状态显示为「运行中」。保存设置后会立即启停服务，无需重启应用。

**连接地址**

```text
http://127.0.0.1:19821/mcp
```

设置页可复制客户端配置 JSON，例如：

```json
{
  "mcpServers": {
    "ai-chat-memory": {
      "url": "http://127.0.0.1:19821/mcp"
    }
  }
}
```

将上述片段按所用客户端的 MCP 配置格式粘贴即可（字段名可能因客户端略有差异，URL 保持不变）。

**能力概览**

- 工具：跨会话搜索、打开会话、分页读消息、会话内定位。
- 资源：`sessions://recent`、`session://{id}`、`session://{id}/messages`。
- 不提供导入、删除或修改设置等写操作。

**安全说明**

- 仅监听本机环回 `127.0.0.1:19821`，不对外开放。
- 当前版本不要求 token；同一台电脑上的其他进程在应用运行且 MCP 开启时，可以读取已同步对话。
- 关闭 MCP 开关后服务会停止并释放端口。

## 6. WebDAV 云同步

在“设置 > 云同步”中填写 WebDAV 地址、远端目录、用户名和密码。启用前先执行“测试连接”；服务器必须支持 `PROPFIND`、`MKCOL`、`GET`、`PUT`、`DELETE`、ETag、`If-Match` 和 `If-None-Match`。应用不依赖 WebDAV `LOCK` 或服务端脚本。

- 首次启用会为现有会话建立本地基线。之后应用启动、本地导入或删除、15 分钟周期以及“立即同步”都会触发同步。
- 同一实体使用最后变更胜出；删除以墓碑传播，离线设备恢复后不会用旧内容覆盖较新的删除。
- 多条变更会打包为 TAR 并使用 Zstandard 压缩，再保存为不可变 `.acmb` 包。
- 明文模式仅校验包完整性。启用加密后，新包使用 Argon2id 和 XChaCha20-Poly1305；历史包保持原有模式。
- WebDAV 密码和同步密码存入系统凭据存储，不写入 `settings.json`。同步密码丢失后，加密包中的历史内容不可恢复。
- “重写云端存档”会创建新的 generation 并重建状态基线，用于清理历史包或更换同步密码。执行前应确认其他设备均已完成同步。
- 删除远端设备记录只清理同步元数据，不撤销该设备已经获得的 WebDAV 凭据。撤销访问需要在 WebDAV 服务端更换密码；加密模式还应更换同步密码并重写存档。

状态含义：`idle` 表示等待触发，`syncing` 表示正在同步，`offline` 表示网络不可达，`auth_error` 表示凭据错误，`needs_unlock` 表示缺少同步密码，`protocol_error` 表示服务器能力、ETag 或包格式不兼容。

排查顺序：先重新测试连接，再确认地址和远端目录没有嵌入用户名或密码；认证错误时重新保存凭据；ETag 错误时检查服务器或代理是否保留条件请求头；包损坏时保留远端文件并查看应用日志，不要手工修改 `.acmb` 或 `head.json`。

## 7. 数据与隐私

- 桌面端 userscript API 只监听本机地址 `127.0.0.1:19820`。
- MCP 只读服务（若启用）监听本机地址 `127.0.0.1:19821`。
- 聊天记录保存在本地 SQLite 数据库中。
- 网页请求必须来自允许的 Origin，并携带客户端标识。
- 启用同步密钥后，还必须提供正确的随机密钥。
- 删除对话会永久删除该会话及其消息，操作无法撤销。

建议定期备份 `chat_memory.db`，尤其是在更改数据目录或重装系统之前。

## 8. 常见问题

### 网页面板显示“连接失败”

1. 确认桌面应用正在运行。
2. 确认桌面端左下角显示“同步服务运行中”。
3. 在脚本菜单中重置后端地址，并刷新网页。
4. 检查安全软件是否阻止本机 `19820` 端口。

### 网页面板提示填写或更新密钥

桌面端已开启同步密钥，但网页脚本未配置或配置不一致。复制桌面端当前密钥，通过 Tampermonkey 脚本菜单重新填写，然后刷新网页。

### 某个平台无法同步

- 确认已登录对应平台，并刷新页面让脚本重新捕获登录状态。
- 通过脚本菜单清除已保存令牌，再刷新页面。
- 尝试“全量同步”补齐缺失记录。
- 平台接口变化时可能需要更新 userscript。

### PNG/JPEG 无法选择

所选内容超过单张图片的画布限制。减少问答组，或改用 Markdown/JSON。图片限制不会影响文本格式导出。

### 更改数据目录后找不到历史记录

确认设置中的目录指向迁移后的数据库位置。不要同时运行多个指向不同数据目录的应用实例；如有备份，可退出应用后恢复 `chat_memory.db`。

### 应用关闭后仍在运行

“关闭窗口后”可能设置为“隐藏到系统托盘”。从托盘菜单选择“退出”，或在设置中改为“退出应用”。

### MCP 客户端连不上

1. 确认桌面应用正在运行，且设置中 MCP 开关已开启。
2. 确认设置页状态为「运行中」，地址为 `http://127.0.0.1:19821/mcp`。
3. 若状态为「异常」且提示端口被占用，结束占用 `19821` 的其他进程后重新打开 MCP 开关。
4. 关闭 MCP 后再开启可强制重新绑定端口；完全退出应用也会停止 MCP。
5. 客户端配置中的 URL 须指向本机环回，不要改成局域网 IP。
